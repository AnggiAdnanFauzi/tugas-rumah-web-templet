# Tugas Rumah Web Templet

Kumpulan proyek template website yang dikembangkan sebagai bagian dari Kerja Praktik (KP).

## Proyek

### 1. Rumah Template Pendidikan (`rumah-template-pendidikan/`)
Landing page katalog template website khusus institusi pendidikan (sekolah, pesantren, kampus, lembaga kursus).

**Tech Stack:** React + Vite + Tailwind CSS v4

```bash
cd rumah-template-pendidikan
npm install
npm run dev
```

### 2. Rumah Templet Kesehatan (`rumah-templet-kesehatan/`)
Template website untuk layanan kesehatan.

**Tech Stack:** React + Vite + Tailwind CSS

```bash
cd rumah-templet-kesehatan
npm install
npm run dev
```
